2. Implementación de Operaciones Unarias 3 Ejercicios

Consultas aplicadas de manera aislada sobre una única relación.

2.1.1 Ejercicio 1 de Selección σ (Autores de CA)

Autores que residen en el estado de California (CA)

σ state = 'CA' (authors) Álgebra Relacional
Expresión LINQ (C#): 
var resultado = context.Authors
                       .Where(a => a.State == "CA")
                       .ToList();
2.1.2 Ejercicio 2 de Selección σ (Rango de Precios)

Libros cuyo precio se encuentra en el rango de $10.00 a $20.00 inclusive

σ price ≥ 10 ∧ price ≤ 20 (titles) Álgebra Relacional
Expresión LINQ (C#): 
var resultado = context.Titles
                       .Where(t => t.Price >= 10.00m && t.Price <= 20.00m)
                       .ToList();
2.1.3 Ejercicio 3 de Selección σ (Tipo Business)

Libros que pertenecen estrictamente a la categoría o tipo 'business'

σ type = 'business' (titles) Álgebra Relacional
Expresión LINQ (C#): 
var resultado = context.Titles
                       .Where(t => t.Type.Trim() == "business")
                       .ToList();
2.2.1 Ejercicio 1 de Proyección π (Nombres y Apellidos)

Extraer únicamente los nombres (au_fname) y apellidos (au_lname) de todos los autores

π au_fname, au_lname (authors) Álgebra Relacional
Expresión LINQ (C#): 
var resultado = context.Authors
                       .Select(a => new { a.AuFname, a.AuLname })
                       .ToList();
2.2.2 Ejercicio 2 de Proyección π (Ciudades Distintas)

Listar las ciudades de residencia de los autores de forma única (eliminando duplicados)

π city (authors) Álgebra Relacional
Expresión LINQ (C#): 
var resultado = context.Authors
                       .Select(a => a.City)
                       .Distinct()
                       .Select(c => new { CiudadUnica = c })
                       .ToList();
2.2.3 Ejercicio 3 de Proyección π (Tipos de Libros)

Obtener el catálogo de categorías o géneros de libros existentes de forma única

π type (titles) Álgebra Relacional
Expresión LINQ (C#): 
var resultado = context.Titles
                       .Select(t => t.Type)
                       .Distinct()
                       .Select(t => new { Categoria = t })
                       .ToList();
2.3.1 Ejercicio 1 de Renombramiento ρ (Campos en Español)

Modificar cabeceras de columnas a etiquetas explícitas en español (Nombre, Apellido)

ρ Nombre ← au_fname, Apellido ← au_lname (authors) Álgebra Relacional
Expresión LINQ (C#): 
var resultado = context.Authors
                       .Select(a => new { Nombre = a.AuFname, Apellido = a.AuLname })
                       .ToList();
2.3.2 Ejercicio 2 de Renombramiento ρ (Atributos de Integración)

Modificar las columnas de identificación de libros para interfaces de integración (Codigo, NombreLibro)

ρ Codigo ← title_id, NombreLibro ← title (titles) Álgebra Relacional
Expresión LINQ (C#): 
var resultado = context.Titles
                       .Select(t => new { Codigo = t.TitleId, NombreLibro = t.Title })
                       .ToList();
2.3.3 Ejercicio 3 de Renombramiento ρ (Ingresos Proyectados)

Proyectar el título y calcular un estimado financiero bajo el alias 'IngresoEstimado'

ρ Titulo ← title, IngresoEstimado ← (price × ytd_sales) (...) Álgebra Relacional
Expresión LINQ (C#): 
var resultado = context.Titles
                       .Where(t => t.Price != null && t.YtdSales != null)
                       .Select(t => new { 
                           Titulo = t.Title, 
                           IngresoEstimado = t.Price * t.YtdSales 
                       })
                       .ToList();

3. Implementación de Operaciones Binarias 3 Ejercicios

Consultas algebraicas fundamentadas en teoría de conjuntos aplicadas a múltiples relaciones.

3.1.1 Ejercicio 1 de Unión ∪ (Ciudades Integradas)

Combinar las ciudades de residencia de los autores con las de localización de las editoriales

π city (authors) ∪ π city (publishers) Álgebra Relacional
Expresión LINQ (C#): 
var ciudadesAutores = context.Authors.Select(a => new { Ciudad = a.City });
var ciudadesEditoriales = context.Publishers.Select(p => new { Ciudad = p.City });

var resultado = ciudadesAutores.Union(ciudadesEditoriales).ToList();
3.1.2 Ejercicio 2 de Unión ∪ (Autores CA y UT)

Unir autores que residen en California (CA) con autores que residen en Utah (UT)

σ state = 'CA' (authors) ∪ σ state = 'UT' (authors) Álgebra Relacional
Expresión LINQ (C#): 
var autoresCA = context.Authors.Where(a => a.State == "CA");
var autoresUT = context.Authors.Where(a => a.State == "UT");

var resultado = autoresCA.Union(autoresUT).ToList();
3.1.3 Ejercicio 3 de Unión ∪ (Premium o Altas Ventas)

Unificar los libros con precio premium (> $20) con libros que poseen altos volúmenes de venta (> 5,000)

σ price > 20 (titles) ∪ σ ytd_sales > 5000 (titles) Álgebra Relacional
Expresión LINQ (C#): 
var caros = context.Titles.Where(t => t.Price > 20.00m);
var vendidos = context.Titles.Where(t => t.YtdSales > 5000);

var resultado = caros.Union(vendidos).ToList();
3.2.1 Ejercicio 1 de Diferencia − (Áreas sin Distribución)

Ciudades que cuentan con autores residentes pero no poseen casas editoras instaladas

π city (authors) − π city (publishers) Álgebra Relacional
Expresión LINQ (C#): 
var ciudadesAutores = context.Authors.Select(a => a.City).Distinct();
var ciudadesEditoriales = context.Publishers.Select(p => p.City).Distinct();

var resultado = ciudadesAutores.Except(ciudadesEditoriales)
                               .Select(c => new { CiudadSinEditorial = c })
                               .ToList();
3.2.2 Ejercicio 2 de Diferencia − (Libros no Business)

Catálogo completo de libros de la editorial excluyendo los que pertenecen a la categoría 'business'

titles − σ type = 'business' (titles) Álgebra Relacional
Expresión LINQ (C#): 
var todosLosLibros = context.Titles;
var librosBusiness = context.Titles.Where(t => t.Type.Trim() == "business");

var resultado = todosLosLibros.Except(librosBusiness).ToList();
3.2.3 Ejercicio 3 de Diferencia − (Contratos fuera de CA)

Autores que poseen un contrato vigente actualmente, excluyendo a los que viven en California (CA)

σ contract = 1 (authors) − σ state = 'CA' (authors) Álgebra Relacional
Expresión LINQ (C#): 
var conContrato = context.Authors.Where(a => a.Contract == true);
var vivenEnCA = context.Authors.Where(a => a.State == "CA");

var resultado = conContrato.Except(vivenEnCA).ToList();
3.3.1 Ejercicio 1 de Producto Cartesiano × (Autores × Editoriales)

Matriz cruzada total (Cross Join) entre todos los autores y el catálogo completo de editoriales

π au_fname, au_lname (authors) × π pub_name (publishers) Álgebra Relacional
Expresión LINQ (C#): 
var resultado = (from a in context.Authors
                 from p in context.Publishers
                 select new 
                 {
                     Autor = a.AuFname + " " + a.AuLname,
                     Editorial = p.PubName
                 }).ToList();
3.3.2 Ejercicio 2 de Producto Cartesiano × (Tiendas × Categorías)

Cruzamiento combinatorio total entre la totalidad de tiendas físicas con los géneros de libros

π stor_name (stores) × π type (titles) Álgebra Relacional
Expresión LINQ (C#): 
var tiposUnicos = context.Titles.Select(t => t.Type).Distinct();

var resultado = (from s in context.Stores
                 from t in tiposUnicos
                 select new 
                 {
                     Tienda = s.StorName,
                     CategoriaProducto = t
                 }).ToList();
3.3.3 Ejercicio 3 de Producto Cartesiano × (Personal × Compañías)

Combinatoria de distribución entre los empleados de la organización y el listado de editoriales activas

π lname (employee) × π pub_name (publishers) Álgebra Relacional
Expresión LINQ (C#): 
var resultado = (from e in context.Employee
                 from p in context.Publishers
                 select new 
                 {
                     ApellidoEmpleado = e.Lname,
                     CompaniaEditorial = p.PubName
                 }).ToList();

Gran Conclusión del Laboratorio

El desarrollo e implementación de este proyecto demostró de manera empírica la convergencia absoluta que existe entre el formalismo matemático del Álgebra Relacional y el desarrollo de software moderno mediante Entity Framework Core y LINQ sobre la base de datos Pubs. Se validó con rigor científico que las operaciones unarias y binarias abstractas poseen un homólogo declarativo directo en C# (donde la Selección σ se mapea mediante predicados en .Where(), la Proyección π a través de restricciones en .Select(), y las operaciones conjuntistas de Unión ∪ y Diferencia − mediante .Union() y .Except()), encontrando en los Tipos Anónimos la resolución más elegante para el operador de Renombramiento (ρ). Asimismo, la arquitectura interactiva estructurada en Windows Forms con 18 botones independientes conectados a un único DataGridView no solo evidenció la capacidad del ORM para resolver de forma implícita la compatibilidad de esquemas y optimizar consultas complejas como el Producto Cartesiano (×), sino que constituyó la estrategia metodológica ideal para la sustentación en localhost, garantizando una comunicación técnica fluida, una validación gráfica inmediata del procesamiento de datos y una participación activa y equitativa de todos los miembros del equipo frente a los indicadores de evaluación del laboratorio.
